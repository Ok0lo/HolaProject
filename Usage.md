# 📖 Использование

В этом документе описано, как установить игру, запустить её из исходников и как работает основной игровой процесс.

## Установка (Installation)

### Для игроков (Готовый билд)
1. Перейдите в раздел [Releases](https://github.com/Ok0lo/HolaProject/releases).
2. Скачайте архив для вашей ОС (Windows/Linux/macOS).
3. Распакуйте архив в любую папку.
4. Запустите исполняемый файл (`.exe` или `.x86_64`).

### Для разработчиков (Запуск из исходников)
Для запуска проекта вам понадобится **Unity Hub** и **Unity Editor** (рекомендуемая версия 2022.3 LTS).

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/Ok0lo/HolaProject.git

# 2. Перейдите в папку проекта
cd HolaProject

# 3. Откройте Unity Hub -> Add -> выберите папку проекта
# 4. Дождитесь импорта всех ассетов
# 5. Откройте сцену Assets/Scenes/MainMenu.unity и нажмите Play
```
