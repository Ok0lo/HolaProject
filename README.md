# Игровое приложение для изучения испанского языка на основе метода контекстной догадки

[![Unity](https://img.shields.io/badge/Unity-2022.3%20LTS-black?style=for-the-badge&logo=unity)](https://unity.com/)
[![C#](https://img.shields.io/badge/C%23-.NET-purple?style=for-the-badge&logo=c-sharp)](https://docs.microsoft.com/en-us/dotnet/csharp/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg?style=for-the-badge)](https://opensource.org/licenses/MIT)

**Краткое описание:** Игровое приложение для изучения испанского языка, которое решает проблему скучной зубрежки. Вместо механического заучивания слов мы используем метод контекстной догадки, увлекательные головоломки и нейросетевой синтез речи (TTS) для естественного погружения в языковую среду.

**Проблема:** Традиционные приложения для изучения языков часто строятся на прямом переводе и карточках. Это формирует пассивное узнавание, но не учит понимать язык в реальном контексте.

**Наше решение:** Приложение предлагает пользователю самостоятельно догадываться о значении незнакомых слов, опираясь на уже известную лексику, логику предложения, визуальные подсказки и игровую ситуацию. Это развивает языковую интуицию и снижает страх перед общением на иностранном языке.

## Основные возможности (Features)

*   **Метод контекстной догадки:** Восстановление пропущенных слов, сопоставление реплик, выбор верного значения по смыслу.
*   **Нейросетевой TTS:** Интеграция синтеза речи для озвучивания испанских слов. Аудио помогает развивать аудирование и служит подсказкой.
*   **Личный словарь:** Система собирает изученные слова. Ошибочные слова возвращаются в новых контекстах.
*   **Плавная прогрессия:** Постепенное усложнение от простых фраз до сложных диалогов.
*   **Автосохранение:** Прогресс записывается в JSON-файл.

## Установка (Installation)

### Для игроков (Готовый билд)
1. Перейдите в раздел [Releases](https://github.com/Ok0lo/HolaProject/releases).
2. Скачайте архив для вашей ОС (Windows/Linux/macOS).
3. Распакуйте архив в любую папку.
4. Запустите исполняемый файл (`.exe` или `.x86_64`).

### Для разработчиков (Запуск из исходников)
Для запуска проекта вам понадобится **Unity Hub** и **Unity Editor** (рекомендуемая версия 2022.3 LTS).

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/Ok0lo/HolaProject.git

# 2. Перейдите в папку проекта
cd HolaProject

# 3. Откройте Unity Hub -> Add -> выберите папку проекта
# 4. Дождитесь импорта всех ассетов
# 5. Откройте сцену Assets/Scenes/MainMenu.unity и нажмите Play
```

## Подробное описание модулей (Module Details)

### Ключевые папки `Assets/`

*   **`Audio/`** — разделена на подпапки для фоновой музыки (BGM), звуковых эффектов (SFX) и кэшированных аудиофайлов движка генерации речи (TTS).
*   **`Data/`** — содержит статические JSON-файлы с базами иностранных слов, конфигурациями уровней, а также динамические файлы игровых сохранений (SaveSlots).
*   **`Prefabs/`** — содержит префабы UI (кнопки, плашки слов, модальные окна) и шаблоны игровых объектов для контекстной догадки.
*   **`Scenes/`** — включает основные экраны приложения: `MainMenu` (главное меню), `Gameplay` (игровой цикл) и `Dictionary` (словарь/прогресс).
*   **`Settings/`** — профили рендеринга (Post-Processing, Universal Render Pipeline) и пресеты графики под разные платформы.

### Архитектура кода `Scripts/`

*   **`Core/`** — «мозг» приложения. Здесь находится логика алгоритма контекстной догадки, менеджеры состояний игры (GameManager), сохранений (SaveManager) и загрузки ресурсов.
*   **`UI/`** — реализация паттерна MVP/MVVM для интерфейса, анимации окон (DOTween) и менеджер навигации по экранам.
