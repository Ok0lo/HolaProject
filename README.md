# 🇪🇸 Gladiacrabs Español: Изучение языка через контекст

**Elevator Pitch:** Игровое приложение для изучения испанского языка, которое решает проблему скучной зубрежки. Вместо механического заучивания слов мы используем метод контекстной догадки, увлекательные головоломки и нейросетевой синтез речи (TTS) для естественного погружения в языковую среду.

**Проблема:** Традиционные приложения для изучения языков часто строятся на прямом переводе и карточках. Это формирует пассивное узнавание, но не учит понимать язык в реальном контексте.

**Наше решение:** Приложение предлагает пользователю самостоятельно догадываться о значении незнакомых слов, опираясь на уже известную лексику, логику предложения, визуальные подсказки и игровую ситуацию. Это развивает языковую интуицию и снижает страх перед общением на иностранном языке.

## Технологический стек
*   **Движок:** Unity
*   **Язык:** C#
*   **Среда разработки:** Visual Studio
*   **Сквозная технология:** Нейросетевой Text-to-Speech (TTS)

## Основные возможности (Features)

*   **Метод контекстной догадки:** Восстановление пропущенных слов, сопоставление реплик, выбор верного значения по смыслу.
*   **Нейросетевой TTS:** Интеграция синтеза речи для озвучивания испанских слов. Аудио помогает развивать аудирование и служит подсказкой.
*   **Личный словарь:** Система собирает изученные слова. Ошибочные слова возвращаются в новых контекстах.
*   **Плавная прогрессия:** Постепенное усложнение от простых фраз до сложных диалогов.
*   **Автосохранение:** Прогресс записывается в JSON-файл.
