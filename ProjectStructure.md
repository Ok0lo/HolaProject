# 📂 Структура проекта

В данном разделе представлена архитектура каталогов игрового проекта в Unity. Структура организована по принципу разделения ответственности, что обеспечивает масштабируемость кода и удобство совместной разработки.

## Дерево каталогов

```text
.
├── 📂 Assets/                  # Основные ресурсы и исходный код проекта
│   ├── 📂 Audio/               # Звуковое сопровождение (BGM, SFX и TTS)
│   ├── 📂 Data/                # Локальные базы данных, конфиги и сохранения
│   ├── 📂 Prefabs/             # Переиспользуемые шаблоны объектов (UI/UX, Gameplay)
│   ├── 📂 Scenes/              # Игровые сцены и экраны
│   ├── 📂 Scripts/             # Архитектура исходного кода (C#)
│   │   ├── 📂 Core/            # Архитектурное ядро, стейт-машины, менеджеры систем
│   │   └── 📂 UI/              # Логика пользовательского интерфейса и навигация
│   ├── 📂 Settings/            # Конфигурации графики, рендера (URP/HDRP) и качества
│   └── 📂 Sprites/             # Визуальные ассеты, текстуры и атласы
├── 📂 Packages/                # Менеджер зависимостей Unity (Package Manager)
└── 📂 ProjectSettings/         # Системные настройки проекта Unity
```

---

## Подробное описание модулей (Module Details)

### Ключевые папки `Assets/`

*   **`Audio/`** — разделена на подпапки для фоновой музыки (BGM), звуковых эффектов (SFX) и кэшированных аудиофайлов движка генерации речи (TTS).
*   **`Data/`** — содержит статические JSON-файлы с базами иностранных слов, конфигурациями уровней, а также динамические файлы игровых сохранений (SaveSlots).
*   **`Prefabs/`** — содержит префабы UI (кнопки, плашки слов, модальные окна) и шаблоны игровых объектов для контекстной догадки.
*   **`Scenes/`** — включает основные экраны приложения: `MainMenu` (главное меню), `Gameplay` (игровой цикл) и `Dictionary` (словарь/прогресс).
*   **`Settings/`** — профили рендеринга (Post-Processing, Universal Render Pipeline) и пресеты графики под разные платформы.

### 💻 Архитектура кода `Scripts/`

*   **`Core/`** — «мозг» приложения. Здесь находится логика алгоритма контекстной догадки, менеджеры состояний игры (GameManager), сохранений (SaveManager) и загрузки ресурсов.
*   **`UI/`** — реализация паттерна MVP/MVVM для интерфейса, анимации окон (DOTween) и менеджер навигации по экранам.
