# 📂 Структура проекта (Project Structure)

## Дерево каталогов

```text
├── Assets/
│   ├── Sprites/        # Спрайты, текстуры
│   ├── Audio/          # Фоновая музыка и кэшированные аудиофайлы TTS
│   ├── Data/           # JSON-файлы с базами слов, уровнями и сохранениями
│   ├── Prefabs/        # Повторно используемые элементы UI и игровых объектов
│   ├── Scenes/         # Сцены Unity (MainMenu, Level1, Dictionary)
│   ├── Scripts/        # Исходный код C#
│   │   ├── Core/       # Логика контекстной догадки, менеджеры состояний
│   │   └── UI/         # Скрипты интерфейса, навигация
│   └── Settings/       # Настройки рендера и качества
├── Packages/           # Зависимости Unity
└── ProjectSettings/
```
